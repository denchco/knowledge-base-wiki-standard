# Standard production profile

New reference implementations use pinned Zensical, the governed DenchCo visual profile, locally served Mermaid and graph runtimes, real 2D/3D Graphify views, built-output browser verification, and identity-verified managed runtime health. The persistent service owns a stable ID and conflict-free loopback endpoint through a serialized, atomically published shared-register reservation, refuses unmanaged listeners, exact-matches twelve governed registry fields plus its generated installed and loaded user-service job, publishes a versioned exact-ID marker, and hands a preview to the browser only through a fail-closed exact canonical-URL command. An ephemeral alternate-port server proves baseline rendering only. Live service status is maintainer-workspace evidence; distribution/CI leaves the persistent runtime requirement not checked. Complete graph verification fails closed when either selected-profile view is missing and exercises both at desktop and mobile widths. Maintenance workspaces satisfy `DKBWS-PROV-001` with Git-interoperable history, filesystem-significant root paths, a colocated Jujutsu workspace, and one disclosed JJ commit at the end of every file-changing development turn after verification and state inspection; Portable Core and explicit distribution/CI checkouts may remain Git-only.
