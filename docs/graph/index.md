# Repository graph

The two interactive views use one generated, relationship-enriched Graphify dataset. The graph assists discovery and inspection; it does not create evidential authority.

- [Open the two-dimensional view](two-dimensional.md).
- [Open the three-dimensional view](three-dimensional.md).
- [Read the Graphify maintenance workflow](../llm-wiki/graphify.md).
- [Return to the system architecture](../architecture.md).

Regenerate the graph with `npm run graph:update`. Do not edit published graph assets directly.
