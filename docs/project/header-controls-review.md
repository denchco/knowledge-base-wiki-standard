The browser gate builds subject-empty, generic fixtures through the pinned real renderer. It tests Chromium and WebKit, both appearances, desktop/mobile, Standard/Wide, reload and navigation. It checks measured control geometry, opacity, hover pairs, contrast, Search pseudo-elements and actual SVG centres within `.5` CSS pixels. Negative rendered probes must reject deliberately broken controls. Generic screenshots show these fixtures, not private consumer pages.

The zoom scope is explicit: rendered CSS layout zoom at 200%, root text resize at 200%, and 320 CSS pixel reflow equivalent to a 1280-pixel viewport at 400%. Native browser-chrome zoom and operating-system magnification are not claimed. The existing runtime and appearance suites remain required alongside the new header gate. The draft PR records the exact execution results for its implementation revision; this description alone is not a passing receipt.
